# SSA — Système de Suivi des Âmes

Application de gestion pastorale pour la Cathédrale des Signes et des Prodiges.
Suivi hebdomadaire des membres via une chaîne hiérarchique : Pasteur → PR → Leaders → Encadreurs.

## Stack
- **Backend** : Node.js, Express, PostgreSQL (Supabase), JWT
- **Frontend** : React, Vite, Tailwind CSS (PWA mobile-first)

## Structure
- `backend/` — API REST
- `frontend/` — Application web PWA
- `docs/` — Documentation et specs API
